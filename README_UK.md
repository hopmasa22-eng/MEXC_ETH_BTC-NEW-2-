# MEXC Futures — бот двох правил (5 хвилин)

Бот надсилає інформаційні сигнали в Telegram і не відкриває угоди автоматично.

## Правило 1
- LONG: №1–3 зелені, №4–5 червоні, №6 будь-яка. Для SHORT — навпаки.
- Якщо №7 закрилася кольором №1–3, надсилається попередження після її закриття.
- Після закриття №8 надсилається сигнал LONG/SHORT.
- Результат за №9–15: хоча б одна свічка початкового кольору — WIN; усі сім протилежного кольору — LOSS.

## Правило 2
- Та сама базова комбінація №1–6.
- Якщо свічка №7 формується протилежного кольору, бот надсилає попередження під час її формування. На початку №7 це приблизно за 5 хвилин до закриття; колір може змінитися.
- Сигнал надсилається лише після закриття №7, якщо вона залишилася протилежного кольору.
- Результат за №8–14: хоча б одна свічка початкового кольору — WIN; усі сім протилежного кольору — LOSS.

## Свічки й кольори
- Використовуються нативні свічки MEXC Futures `Min5`.
- DOJI (open = close) не вважається ні зеленою, ні червоною.
- Час повідомлень показується за Києвом.
- Українські повідомлення та JSON стану зберігаються в UTF-8.

## Розгортання в Railway
1. Розпакуйте ZIP і завантажте в GitHub-репозиторій.
2. Створіть сервіс Railway із цього репозиторію.
3. У Railway → Variables задайте:
   - `TELEGRAM_BOT_TOKEN` — токен від BotFather.
   - `TELEGRAM_CHAT_ID` — ID чату; кілька ID можна вказати через кому.
   - `MEXC_SYMBOLS=BTCUSDT,ETHUSDT`
   - `POLL_SECONDS=10`
   - `TEST_MODE=false`
4. Команда запуску: `python -u bot.py` (вже задана в конфігурації).

## Перевірка
Локально виконайте `pip install -r requirements.txt`, потім `TEST_MODE=true python bot.py`. Тест перевіряє базові умови, український текст та емодзі без запитів до MEXC і без повідомлень у Telegram.

# Бот сигналів MEXC Futures — 10-хвилинні свічки

Бот надсилає інформаційні повідомлення в Telegram. Автоматично угоди не відкриває.

## Правило 1
- LONG: свічки №1–3 зелені, №4–5 червоні, №6 може бути будь-якого кольору. Для SHORT кольори навпаки.
- Якщо свічка №7 закрилася кольором свічок №1–3, надсилається попередження.
- Після закриття свічки №8 надсилається сигнал LONG або SHORT.
- Перевірка результату: свічки №9–15. Хоча б одна свічка початкового кольору означає WIN (перемога); якщо всі сім протилежного кольору — LOSS (поразка).

## Правило 2
- Використовується та сама базова комбінація свічок №1–6.
- Якщо свічка №7 під час формування має протилежний колір, надсилається попередження. Якщо це відбувається на початку свічки, до її закриття лишається приблизно 10 хвилин; колір може змінитися.
- Сигнал надсилається лише після закриття свічки №7, якщо вона залишилася протилежного кольору.
- Перевірка результату: свічки №8–14. Хоча б одна свічка початкового кольору означає WIN (перемога); якщо всі сім протилежного кольору — LOSS (поразка).

## Як формуються 10-хвилинні свічки
- Бот завантажує 1-хвилинні дані MEXC Futures (`Min1`) і об'єднує кожні десять послідовних хвилин в одну 10-хвилинну свічку.
- Закрита 10-хвилинна свічка використовується лише тоді, коли наявні всі десять 1-хвилинних свічок. Неповні свічки не враховуються як закриті.
- Свічка з однаковими ціною відкриття та закриття (DOJI) не є ні зеленою, ні червоною. Сама по собі вона не підтверджує LOSS.
- Час повідомлень — київський. Український текст збережено в кодуванні UTF-8.

## Налаштування в Railway
1. Завантажте в GitHub вміст цього ZIP та під'єднайте репозиторій до Railway.
2. У розділі Railway → Variables задайте:
   - `TELEGRAM_BOT_TOKEN` — токен бота від BotFather.
   - `TELEGRAM_CHAT_ID` — ID чату. Кілька ID можна розділити комами.
   - `MEXC_SYMBOLS=BTCUSDT,ETHUSDT`
   - `POLL_SECONDS=10`
   - `TELEGRAM_MIN_INTERVAL=1.2` — мінімальна пауза між повідомленнями.
   - `TEST_MODE=false`
3. Команда запуску: `python -u bot.py`.

## Захист від повторів і помилки Telegram 429
- Бот перевіряє лише свіжі свічки-тригери, а не надсилає сигнали за всією історією після запуску.
- Якщо Telegram повертає `429`, бот чекає час, указаний у `retry_after`, перш ніж повторити запит.
- Стан 10-хвилинного бота зберігається в окремих файлах `state_10m_...json`, щоб не змішувати його зі станом старої версії на 5 хвилин.
- Не запускайте кілька копій бота з одним токеном одночасно. Зупиніть старі Railway-сервіси перед запуском цієї версії.

## Перевірка без надсилання повідомлень
Встановіть залежності командою `pip install -r requirements.txt`, а потім запустіть `TEST_MODE=true python bot.py`. Цей тест не звертається до MEXC і не надсилає повідомлень у Telegram.
